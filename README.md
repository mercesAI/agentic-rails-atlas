# Agentic Rails Atlas

A personal, offline-capable reference site for eight agent identity, checkout and payment protocols: ERC-8004, x402, Visa Trusted Agent Protocol (TAP), the Agentic Commerce Protocol (ACP, OpenAI and Stripe), the Universal Commerce Protocol (UCP), the Machine Payments Protocol (MPP, Stripe and Tempo), the Agent Payments Protocol (AP2) and Mastercard Agent Pay.

Every factual statement on the site is a claim with a source and a confidence (`verified`, `reported` or `unverified`). Numbers carry an "as of" date. Each protocol page has 20 sections, from a summary to a plain-language Simplified Technical English (STE) version, diagrams, a simulation playground, security, controls and observability lenses, and a self-test.

## Run it

Requirements: Node 22.12 or later, pnpm 10 or later.

```
pnpm install
pnpm dev        # local development server
pnpm build      # merge content, build the search index, build the static site into dist/
pnpm preview    # serve dist/ at http://localhost:4321
```

Astro 7 runs one preview server per project. Stop it with `pnpm exec astro preview stop`.

## How content is organized

- `src/content/protocols/<slug>/`: one folder per protocol. `index.mdx` holds the frontmatter (key facts, stewards, status) and the explanation text with all reading modes; `ste.mdx` holds the STE version; the JSON sidecars hold claims, sources, personas, resources, security, controls, compliance, observability, ecosystem and costs, timeline, code, FAQ, open questions, quiz and flashcards.
- `src/content/flows/`, `states/`, `diagrams/`: sequence flows, state machines and hand-written Mermaid diagrams. Flows drive both the rendered diagram and the interactive flow player.
- `src/content/scenarios/`, `orbit/`, `personas/`, `glossary/`: cross-cutting content.
- `research/`: the research files each page was written from (dossiers, claims, sources, policy, market, fees, publications, orbit, glossary draft). `research/vendor/` holds read-only clones of the spec repositories and is not committed.
- `src/playgrounds/<slug>/`: client-side simulations. No real funds, keys or network calls.
- Shared files (`src/content/sources/sources.json`, `publications/publications.json`, `glossary/terms.json`, `compare.json`, `controls-map.json`, `relations.json`, `timeline-global.json`) are generated by `pnpm merge` from the per-protocol sidecars and the research files. Do not edit them by hand.
- `docs/ARCHITECTURE.md` is the contract between the parts; `docs/briefs/` holds the briefs used to write, verify and extend content.

## Add things

- **A source:** add a `Source` record to the owning protocol's `sources.json` (id prefix `src-<slug>-`), then cite it from a claim. Never copy another protocol's source records; cite their ids.
- **A claim:** add it to the protocol's `claims.json` with `sources`, `confidence` and, for any number or date, `asOf`. Cite it in MDX with `<Cite ids="clm-<slug>-NNN" />`.
- **A paper:** add a verified entry to a `research/publications.*.json` file (verified through DataCite, Crossref, DOI negotiation, the arXiv API or the publisher page), then run `pnpm merge`.
- **A protocol:** follow `docs/briefs/RESEARCH_BRIEF.md`, then `docs/briefs/WRITER_BRIEF.md`, then `docs/briefs/VERIFIER_BRIEF.md`. Add the slug to `PROTOCOL_SLUGS` in `src/lib/schemas.ts`.

## Quality gates

```
pnpm check              # astro check, tsc, eslint, content schema validation
pnpm test               # Vitest unit tests
pnpm e2e                # Playwright and axe (set PLAYWRIGHT_CHANNEL=chrome to use the system Chrome)
pnpm lint:style         # em dashes and banned phrases fail; long sentences warn
pnpm lint:ste           # STE sentence limits
pnpm verify:sources     # every claim and sidecar source id resolves
pnpm verify:coverage    # per-protocol thresholds (sections, words, diagrams, resources, papers, quiz)
pnpm verify:citations   # re-verifies every publication online
pnpm verify:links       # checks every external URL
pnpm gates              # the fast set in one command
```

## Deploy

The site is a static build in `dist/`, so any static host works. The default target is Cloudflare Pages: `wrangler.toml` points at `dist/`, and `public/_headers` sets the Content Security Policy (with hashes for inline scripts written at build time), `Referrer-Policy` and `Permissions-Policy`. Run `pnpm deploy:preview` to build and print the deploy command (`npx wrangler pages deploy dist --project-name agentic-rails-atlas`). The GitHub Actions workflow in `.github/workflows/gates.yml` runs the gates on every push without any secrets and deploys only on a `v*` tag, using `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` repository secrets. No token is ever stored in the repository.

## Optional data

- `pnpm data` refreshes GitHub, npm, PyPI and x402 Bazaar snapshots. It never fails the build.
- The ERC-8004 Agent0 subgraph fetch runs only when `GRAPH_API_KEY` (or `AGENT0_SUBGRAPH_URLS`) is set; see `.env.example`.

## Optional STE vocabulary check

The STE linter checks the public ASD-STE100 Issue 9 writing rules. If you have your own copy of the standard, put the approved words one per line in `ste/approved-words.local.txt`; the linter then also flags words that are neither approved nor in the technical-noun list. That file is gitignored and must never be committed, because ASD holds the copyright.
