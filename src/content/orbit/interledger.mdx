Open Payments has a public specification and SDK repository and a reference implementation, Rafiki; the npm package `@interledger/open-payments` reached 7.4.0 on 2026-03-11 and was still the latest release on 2026-11-14. <Cite ids="src-orbit-interledger-op-repo src-orbit-interledger-op-npm" /> Web Monetization is a Draft Community Group Report, republished on 2026-09-15 by Interledger Foundation editors, and not a W3C standard. <Cite ids="src-orbit-interledger-wm-spec" /> On 2026-10-22 the Foundation's chief technology officer set out its view of Web Monetization for AI agents: a monetization link tag gives an agent a machine-readable signal that a site accepts payments, so an agent with a budget can stream small payments to the site's Open Payments wallet address, while [x402](/p/x402/) and [MPP](/p/stripe-mpp/) charge a set price before content is served. The post says Web Monetization is not a competitor to those two but serves a different purpose; it is a position post, not an agent program, product or specification change. <Cite ids="src-orbit-interledger-wm-agentic-age" /> As of 2026-11-14 no Foundation agent program was found, none of the eight reference Open Payments, and a community post that explores it as an x402 settlement rail is one researcher's work (reported). <Cite ids="src-orbit-interledger-blog src-orbit-interledger-community-x402" />
