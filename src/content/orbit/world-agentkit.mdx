World announced the AgentKit beta on 2026-03-17, and the docs still label it beta. <Cite ids="src-orbit-kya-world-agentkit-blog src-orbit-kya-world-agentkit-docs" /> A person registers an agent's wallet in AgentBook with a World ID proof. An [x402](/p/x402/) site then asks the agent to sign a CAIP-122 message, looks up the human behind the wallet in AgentBook and applies its own access policy; the client sends an `agentkit` header and tries this check before paying. The npm package `@worldcoin/agentkit` reached 0.2.1 on 2026-08-24 and depends on `@x402/core`. <Cite ids="src-orbit-kya-world-agentkit-repo" /> The x402 docs list it as a third-party extension for verifying human-backed agents. <Cite ids="src-x402-docs-devtools" />
