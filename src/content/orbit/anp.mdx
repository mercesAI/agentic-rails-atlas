ANP targets agents that find and talk to each other on the open internet rather than inside one platform. A 2025 survey of agent interoperability protocols groups it with MCP, IBM's Agent Communication Protocol and A2A, and describes it as using decentralized identifiers (DIDs) and JSON-LD for open-network discovery and secure collaboration. <Cite ids="src-arxiv-2505-02279" /> The project has released specification sets on GitHub since V1.0 (2025-05-19), followed by v1.1 (2026-06-27) and ANP 1.2 (2026-09-24). In 1.2 the authentication, `did:wba` identity, naming, agent description and discovery documents are released, while DID-based authorization (ANP-05), the meta-protocol (ANP-06) and a payment adaptation (ANP-10) remain drafts (as of 2026-11-14). <Cite ids="src-orbit-anp-repo" /> ANP-10 adapts [AP2](/p/ap2/) to ANP, with CartMandate, PaymentMandate and DeliveryReceipt credentials and QR payments through Alipay and WeChat Pay; it uses AP2 v0.1 names rather than AP2 v0.2's mandates. <Cite ids="src-orbit-anp-10" /> None of the eight protocols reference ANP in their specifications.
