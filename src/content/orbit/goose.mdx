goose is an open-source AI agent from Block that gains its abilities through MCP servers. Block contributed it to the Agentic AI Foundation when the Linux Foundation formed the foundation on 2025-12-09, together with Anthropic's MCP and OpenAI's AGENTS.md. <Cite ids="src-gloss-aaif-lf" /> The x402 specification does not mention goose, and no reference was found in the other seven protocols' specifications (searched 2026-10-19). <Cite ids="src-x402-repo" /> goose's documentation does include a tutorial, added on 2026-03-07, for a third-party MCP server (Spraay) whose tools charge $0.001 to $0.01 in USDC per call over x402 on Base. <Cite ids="src-orbit-goose-spraay-tutorial" /> That server holds the wallet key and pays over HTTP itself. As an MCP client goose could in principle call the MCP transports that [x402](/p/x402/) and [MPP](/p/stripe-mpp/) define, but that was not verified (as of 2026-10-19). <Cite ids="src-x402-transport-mcp-v2 src-stripe-mpp-mcp-transport" />
