Payments MCP, launched on 2025-10-23, is a local MCP server that lets an agent create a wallet, fund it through an onramp and pay x402 services; Coinbase tested it with Claude Desktop, Claude Code, Codex, Gemini and Cherry Studio. <Cite ids="src-orbit-coinbase-payments-mcp src-orbit-coinbase-payments-mcp-repo" /> On 2026-10-19 Coinbase documented it as Agentic Wallet MCP, still installed from the `@coinbase/payments-mcp` package. <Cite ids="src-orbit-coinbase-agentic-wallet-mcp-docs" /> Agentic Wallets, launched on 2026-02-11, were described as keeping keys in Trusted Execution Environments and applying session caps, per-transaction limits and KYT screening, with x402 as the payment protocol. <Cite ids="src-orbit-coinbase-agentic-wallets src-orbit-coinbase-awal-docs src-x402-agentic-wallets-coverage" /> By 2026-11-14 the Agentic Wallet pages, including the MCP and CLI guides, answered 404, and the CDP changelog no longer carried the 2026-02-11 launch entry; no retirement announcement was found, and the npm packages were not marked deprecated. <Cite ids="src-x402-cdp-agentic-wallet src-x402-cdp-changelog" />

Fortune reported the launch of Base MCP on 2026-05-26 and tied it to x402, which Coinbase released in May 2025. <Cite ids="src-orbit-coinbase-base-mcp-fortune" /> Cointelegraph reported the next day that users can ask Claude or ChatGPT to transfer funds or swap tokens, and that the user confirms or cancels each action in the wallet. The agent has no access to private keys (reported). <Cite ids="src-orbit-coinbase-base-mcp-cointelegraph" /> Base MCP is now called Wallet MCP. Coinbase's docs say every write action needs the user's approval, and on 2026-11-14 they say it pays x402 services in USDC on Base or Base Sepolia with the exact, upto and auth-capture schemes, with a wallet signature for each paid request. <Cite ids="src-orbit-base-mcp-moved src-orbit-coinbase-wallet-mcp-docs src-x402-cdp-agentic-accounts" />

CDP's agentic accounts overview of 2026-11-14 lists two ways for an agent to pay x402 services: Wallet MCP, and Coinbase for Agents, which connects an agent to a Coinbase account through a remote MCP server or a local CLI. <Cite ids="src-x402-cdp-agentic-accounts" /> Coinbase originated [x402](/p/x402/), whose governance now sits with the x402 Foundation at the Linux Foundation. <Cite ids="src-x402-lf-july" />
