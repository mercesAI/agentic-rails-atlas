Payments MCP, launched on 2025-10-23, is a local MCP server that lets an agent create a wallet, fund it through an onramp and pay x402 services; Coinbase tested it with Claude Desktop, Claude Code, Codex, Gemini and Cherry Studio. <Cite ids="src-orbit-coinbase-payments-mcp src-orbit-coinbase-payments-mcp-repo" /> Agentic Wallets, launched on 2026-02-11, keep keys in Trusted Execution Environments and apply session caps, per-transaction limits and KYT screening, with x402 as the payment protocol. <Cite ids="src-orbit-coinbase-agentic-wallets src-orbit-coinbase-awal-docs src-x402-agentic-wallets-coverage" /> Fortune reported on 2026-05-26 that Base MCP lets Claude or ChatGPT propose transfers and swaps that the user confirms in the Base wallet, without the agent holding keys (reported). <Cite ids="src-orbit-coinbase-base-mcp-fortune" /> Coinbase originated [x402](/p/x402/), whose governance now sits with the x402 Foundation at the Linux Foundation. <Cite ids="src-x402-lf-july" />
