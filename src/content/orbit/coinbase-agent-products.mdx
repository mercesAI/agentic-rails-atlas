Payments MCP, launched on 2025-10-23, is a local MCP server that lets an agent create a wallet, fund it through an onramp and pay x402 services; Coinbase tested it with Claude Desktop, Claude Code, Codex, Gemini and Cherry Studio. <Cite ids="src-orbit-coinbase-payments-mcp src-orbit-coinbase-payments-mcp-repo" /> Coinbase now documents it as Agentic Wallet MCP, still installed from the `@coinbase/payments-mcp` package (as of 2026-10-19). <Cite ids="src-orbit-coinbase-agentic-wallet-mcp-docs" /> Agentic Wallets, launched on 2026-02-11, keep keys in Trusted Execution Environments and apply session caps, per-transaction limits and KYT screening, with x402 as the payment protocol. <Cite ids="src-orbit-coinbase-agentic-wallets src-orbit-coinbase-awal-docs src-x402-agentic-wallets-coverage" /> Fortune reported the launch of Base MCP on 2026-05-26 and tied it to x402, which Coinbase released in May 2025. <Cite ids="src-orbit-coinbase-base-mcp-fortune" /> Cointelegraph reported the next day that users can ask Claude or ChatGPT to transfer funds or swap tokens, and that the user confirms or cancels each action in the wallet. The agent has no access to private keys (reported). <Cite ids="src-orbit-coinbase-base-mcp-cointelegraph" /> Base MCP is now called Wallet MCP; Coinbase's docs say every write action needs the user's approval and that it pays x402-enabled APIs on Base and Base Sepolia (as of 2026-10-19). <Cite ids="src-orbit-base-mcp-moved src-orbit-coinbase-wallet-mcp-docs" /> Coinbase originated [x402](/p/x402/), whose governance now sits with the x402 Foundation at the Linux Foundation. <Cite ids="src-x402-lf-july" />
