AGENTS.md is a plain Markdown file in a repository that gives coding agents the project instructions and context they need. OpenAI contributed it to the Agentic AI Foundation when the Linux Foundation formed the foundation on 2025-12-09, alongside Anthropic's MCP and Block's goose. <Cite ids="src-gloss-aaif-lf" /> It carries no payment or commerce semantics, but repositories of three of the eight ship one: the [UCP](/p/ucp/) repository at its root, the `mppx` SDK repository and the mpp.dev docs repository for [MPP](/p/stripe-mpp/), and the [x402](/p/x402/) repository, as `docs/AGENTS.md` for its documentation. <Cite ids="src-ucp-repo src-stripe-mpp-mppx-repo src-stripe-mpp-docs-repo src-x402-repo" />
