ACK's v1 releases use W3C DIDs and Verifiable Credentials, with payment receipts issued as credentials; the latest release is `agentcommercekit` 0.11.0 of 2026-08-04. <Cite ids="src-orbit-kya-ack-repo src-orbit-kya-ack-docs" /> ACK v2 has not shipped. On 2026-08-27 Catena opened a draft pull request, "RFC: ACK-ID + ACK-Pay v2", which calls itself a proposal and was still open on 2026-10-11. It would replace credentials with plain JOSE grants (`typ` `grant+jwt` with a required `cnf.jkt` key binding), carry grants in a signed `Grant` header under RFC 9421 so Web Bot Auth infrastructure can check them, and give ACK-Pay a profile that adopts the [x402](/p/x402/) offer and receipt artifacts. It also renames "mandate" to "grant" to avoid confusion with [AP2](/p/ap2/). <Cite ids="src-orbit-kya-ack-v2-rfc" /> Catena appears among Agent Pay for Machines participants for [Mastercard Agent Pay](/p/mastercard-agent-pay/). <Cite ids="src-mcap-ap4m-2026" />
