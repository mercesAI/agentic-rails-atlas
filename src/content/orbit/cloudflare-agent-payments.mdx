Cloudflare co-founded the x402 Foundation with Coinbase (announced 2025-09-23), and its Monetization Gateway entered closed beta on 2026-09-30 for eligible US-based sellers and buyers, settling USDC on Base through Coinbase's [x402](/p/x402/) facilitator; the separate credit-backed `cloudflare:402` batch-settlement network in the x402 spec is not the beta's settlement path. <Cite ids="src-x402-cf-blog-foundation src-x402-cf-mg-beta src-x402-cf-changelog src-x402-scheme-batch-cf src-x402-gh-pr-1145" /> Cloudflare Wallets were announced on 2026-08-04 with only handle reservation open, and NET Dollar, announced on 2025-09-25 as a planned US dollar-backed stablecoin, had no launch found as of 2026-10-11. <Cite ids="src-orbit-cloudflare-wallets-blog src-orbit-cloudflare-wallets-pr src-orbit-cloudflare-wallets-docs src-orbit-cloudflare-net-dollar" /> Cloudflare verifies [Visa TAP](/p/visa-tap/) and [Mastercard Agent Pay](/p/mastercard-agent-pay/) signatures at its edge and, since 2026-07-01, lists signed agents as a category of Verified Bots. <Cite ids="src-visa-tap-cf-blog src-cf-verified-bots" /> The Radar API needs an API token, and Radar data is licensed under CC BY-NC 4.0. <Cite ids="src-orbit-cloudflare-radar-api" />
