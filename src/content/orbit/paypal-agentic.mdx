PayPal announced Agent Ready and Store Sync on 2025-10-28; Store Sync was available first and Agent Ready payments were slated for early 2026 (reported), and both are described in PayPal's developer docs. <Cite ids="src-orbit-paypal-docs src-orbit-paypal-dc360" /> The same day PayPal said it would adopt [ACP](/p/openai-acp/) and run an ACP server for its merchants, and it signed the ACP corporate CLA on 2026-04-16. <Cite ids="src-paypal-acp src-openai-acp-cla-signatories" /> PayPal is a listed PSP for the ChatGPT payment sheet beta, a launch partner of Microsoft Copilot Checkout (2026-01-08), a listed [UCP](/p/ucp/) endorser and a named [AP2](/p/ap2/) launch collaborator. <Cite ids="src-openai-apps-monetization src-ms-copilot-checkout src-ucp-site src-ap2-gcloud-launch" /> On 2025-10-27 Google Cloud and PayPal announced a merchant solution in which a PayPal Agent, in line with AP2, would handle checkout over A2A; the post describes AP2 v0.1 mandates, and live use is unverified. <Cite ids="src-ap2-paypal-gcloud" />
