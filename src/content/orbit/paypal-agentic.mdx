PayPal announced Agent Ready and Store Sync on 2025-10-28, and both are described in PayPal's developer docs, where merchants still request access to the agentic commerce services through a form (as of 2026-11-21). <Cite ids="src-orbit-paypal-docs src-orbit-paypal-dc360" /> As read 2026-11-21, the Agent Ready docs list three integration paths across two protocols: [ACP](/p/openai-acp/) for ChatGPT, with delegated payment tokens through Braintree, and [UCP](/p/ucp/) for Google AI Mode and Gemini, with the Google Pay payment handler processed by Braintree or by PayPal's Orders v2 API. <Cite ids="src-openai-acp-paypal-agent-ready" /> On 2026-11-17 Visa named PayPal among the initial participants in the acceptance phase of [Agentic Ready](/orbit/visa-intelligent-commerce/), its readiness program for agent payments: Visa says PayPal is working with it to expand acceptance of Visa agentic tokens across PayPal's merchant network, so that merchants can process tokenized payments started by AI agents through their existing PayPal integration. <Cite ids="src-visa-tap-agentic-ready-acceptance" /> That is announced work in a testing program, not a fourth integration path: the Agent Ready docs do not mention Visa, and Visa's release does not tie PayPal's work to [Visa TAP](/p/visa-tap/). <Cite ids="src-openai-acp-paypal-agent-ready src-visa-tap-agentic-ready-acceptance" /> PayPal had said on 2025-10-28 that it would adopt ACP and run an ACP server for its merchants, and it signed the ACP corporate CLA on 2026-04-16. <Cite ids="src-paypal-acp src-openai-acp-cla-signatories" /> On 2026-09-16 PayPal announced that it is extending optional WebMCP support through its JavaScript SDK, limited for now to Store Sync merchants, who can ask their PayPal account manager about early enablement: a compatible AI assistant can search, build the cart and start checkout, and the buyer then signs in to PayPal and approves the payment there. <Cite ids="src-orbit-paypal-webmcp-blog" /> Meta's own posts name PayPal among the ways Meta's Muse agent pays: Muse launched on 2026-09-08 checking out with Stripe's Link, and on 2026-09-24 Meta said it was adding Shop Pay and PayPal for payments. <Cite ids="src-openai-acp-meta-muse src-openai-acp-meta-connect-2026" /> PayPal is a listed PSP for the ChatGPT payment sheet beta, a listed UCP endorser and a named [AP2](/p/ap2/) launch collaborator; it was also a launch partner of Microsoft Copilot Checkout on 2026-01-08, but Microsoft's Copilot Checkout page no longer named PayPal on 2026-11-14. <Cite ids="src-openai-apps-monetization src-ucp-site src-ap2-gcloud-launch src-ms-copilot-checkout src-ucp-microsoft-page" /> On 2025-10-27 Google Cloud and PayPal announced a merchant solution in which a PayPal Agent, in line with AP2, would handle checkout over A2A; the post describes AP2 v0.1 mandates, and live use is unverified. <Cite ids="src-ap2-paypal-gcloud" />
