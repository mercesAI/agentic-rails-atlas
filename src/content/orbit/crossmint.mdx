Crossmint launched the Agentic Cards API publicly on 2026-06-02, built on Visa Intelligent Commerce and Basis Theory: developers connect eligible US-issued Visa cards to AI agents as tokenized credentials with spend limits, and issuer approval and controls still apply. <Cite ids="src-orbit-crossmint-launch" /> On 2026-09-17 it added a universal vault for agent cards, an SDK that stores any card a user provides in a PCI-compliant vault for the agent to spend from. <Cite ids="src-orbit-crossmint-vault" /> Agent Checkouts (2026-09-25) is one headless API that completes an order at an online store through an embedded option such as Shop Pay, an agentic commerce protocol or browser automation, and uses Visa Intelligent Commerce or Mastercard Agent Pay where the card is enrolled. <Cite ids="src-orbit-crossmint-agent-checkouts" /> The Agent Commerce Toolkit (2026-10-08), which Crossmint calls live and self-serve, combines card storage, network credentials and checkout in one integration: where a card supports it, it uses Visa Intelligent Commerce and [Mastercard Agent Pay](/p/mastercard-agent-pay/) tokenized credentials as scoped virtual cards with expiry dates and spend limits, and it checks out through Shop Pay, [UCP](/p/ucp/) or browser automation. These network and protocol uses are Crossmint's own statements. <Cite ids="src-orbit-crossmint-toolkit" /> On 2026-11-18 Crossmint launched Menta, an open-source plugin built on the toolkit that lets an AI assistant buy for its user. It is listed in the ChatGPT, Devin and Grok Bot plugin marketplaces, and other assistants, such as Claude and Meta's Muse, take it through a setup prompt. Crossmint says the card stays in a PCI-compliant vault and the assistant never sees its number, the user approves a spending limit and how long it lasts or approves each purchase, and Menta checks out through the store's own API, an agent protocol or a browser built for checkout. It pays with the user's own card, and Crossmint says it uses no one-time virtual cards, so rewards, statements and refunds work as usual; it can also pay with a card saved at the store, Shop Pay, Pix or Bizum. The post names no protocol and does not say whether Menta uses the network credentials described above. Crossmint reports that in its own test at 3,000 stores Menta completed 91% of purchases, 5 to 10 times faster than general-purpose agents using browser checkouts, and warns that it will not get every store right yet. <Cite ids="src-orbit-crossmint-menta" /> The repository `Crossmint/menta`, created on 2026-11-04, is Apache-2.0 and had no releases on 2026-11-21. <Cite ids="src-orbit-crossmint-menta-repo" /> As of 2026-11-21 Crossmint's price list gives Agent Checkout 1,000 free checkouts a month, then $0.05 per checkout, and Agent Cards 1,000 free cards a month, then volume pricing, still listing scoped one-time credentials among the Agent Cards features. <Cite ids="src-orbit-crossmint-pricing" /> The SDK `Crossmint/crossmint-sdk` is Apache-2.0. <Cite ids="src-orbit-crossmint-sdk" /> None of the posts says whether [Visa TAP](/p/visa-tap/) is used, so the link to TAP runs through Visa Intelligent Commerce tokens. <Cite ids="src-orbit-crossmint-launch src-orbit-crossmint-toolkit" />
