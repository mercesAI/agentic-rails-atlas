Crossmint launched the Agentic Cards API publicly on 2026-06-02, built on Visa Intelligent Commerce and Basis Theory: developers connect eligible US-issued Visa cards to AI agents as tokenized credentials with spend limits, and issuer approval and controls still apply. <Cite ids="src-orbit-crossmint-launch" /> On 2026-09-17 it added a universal vault for agent cards, an SDK that stores any card a user provides in a PCI-compliant vault for the agent to spend from. <Cite ids="src-orbit-crossmint-vault" /> Agent Checkouts (2026-09-25) is one headless API that completes an order at an online store through an embedded option such as Shop Pay, an agentic commerce protocol or browser automation, and uses Visa Intelligent Commerce or Mastercard Agent Pay where the card is enrolled. <Cite ids="src-orbit-crossmint-agent-checkouts" /> The Agent Commerce Toolkit (2026-10-08), which Crossmint calls live and self-serve, combines card storage, network credentials and checkout in one integration: where a card supports it, it uses Visa Intelligent Commerce and [Mastercard Agent Pay](/p/mastercard-agent-pay/) tokenized credentials as scoped virtual cards with expiry dates and spend limits, and it checks out through Shop Pay, [UCP](/p/ucp/) or browser automation. These network and protocol uses are Crossmint's own statements. <Cite ids="src-orbit-crossmint-toolkit" /> As of 2026-11-14 Crossmint's price list gives Agent Checkout 1,000 free checkouts a month, then $0.05 per checkout, and Agent Cards 1,000 free cards a month, then volume pricing. <Cite ids="src-orbit-crossmint-pricing" /> The SDK `Crossmint/crossmint-sdk` is Apache-2.0. <Cite ids="src-orbit-crossmint-sdk" /> None of the posts says whether [Visa TAP](/p/visa-tap/) is used, so the link to TAP runs through Visa Intelligent Commerce tokens. <Cite ids="src-orbit-crossmint-launch src-orbit-crossmint-toolkit" />
