OASF is AGNTCY's standardized schema system for agent capabilities, interactions and metadata, so that directories and other agents can read what an agent offers. <Cite ids="src-gloss-oasf" /> The ERC-8004 best-practices guide credits OASF from AGNTCY, which it says is now part of the Linux Foundation, with standardized taxonomies for agent capabilities. <Cite ids="src-erc-8004-bp-registration" /> In [ERC-8004](/p/erc-8004/) the registration file example lists an `OASF` service at version 0.8, and feedback entries may carry `oasf.skills` and `oasf.domains`. <Cite ids="src-erc-8004-spec" />
