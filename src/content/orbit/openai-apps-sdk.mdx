OpenAI files this documentation under Plugins: the /apps-sdk URLs have redirected to /plugins since at least 2026-08-09 (Wayback), and published plugins run in ChatGPT and Codex. <Cite ids="src-openai-apps-monetization src-scn-chatgpt-plugin-auth" /> A plugin connects ChatGPT to a developer's Model Context Protocol (MCP) server; DevDay 2026 (2026-09-29) added Plugin Extensions, which package panels, viewers and forms with a plugin, and MCP Events, which deliver webhooks under the draft MCP Events specification. <Cite ids="src-scn-chatgpt-devday-2026" /> The checkout reference, unchanged when read on 2026-11-14, makes external checkout on the developer's own domain the recommended and generally available path, with approval limited to plugins for physical goods; a second path shows only payment methods the customer already saved with the merchant. <Cite ids="src-openai-apps-monetization" /> The ChatGPT payment sheet is a private beta for select marketplaces: the widget calls `window.openai.requestCheckout`, ChatGPT sends a payment token to the developer's MCP server in a `complete_checkout` tool call, and the merchant's payment service provider (PSP: Adyen, Checkout.com, Fiserv, PayPal, Stripe or Worldpay) charges it. <Cite ids="src-openai-apps-monetization" /> OpenAI's plugin guidelines call that sheet Instant Checkout, in beta for select marketplace partners, require external checkout otherwise and allow commerce only in physical goods; their prohibited goods list names categories such as tobacco and nicotine, weapons and prescription medications, and alcohol is not on it. <Cite ids="src-scn-chatgpt-plugin-guidelines" /> Raw payment methods require the [ACP](/p/openai-acp/) Delegate Payment endpoint and Payment Card Industry Data Security Standard (PCI DSS) Level 1. <Cite ids="src-openai-apps-monetization" /> The ACP README still points merchants to OpenAI's documentation, which now opens on the Commerce in ChatGPT partner playbook and no longer describes ACP. <Cite ids="src-openai-acp-readme src-openai-commerce-playbook" />

OpenAI's commerce guidance of 2026-11-13 recommends headless plugins, because iframe-based MCP UI is not supported in dots, with tools for product lookup, carts and, where supported, checkout and order history; lookup and carts should work in guest mode. <Cite ids="src-openai-commerce-build-plugin" /> A checkout tool that cannot finish a step returns a `continue_url`, ideally a one-time authenticated link, so checkout continues on the merchant's site, and OpenAI says it is still working on how plugins and [ChatGPT Wallet](/orbit/chatgpt-wallet/) interact. <Cite ids="src-openai-commerce-build-plugin" /> An authenticated MCP server implements OAuth 2.1 under the MCP authorization specification, which OpenAI's auth guide links at revision 2025-11-25 while its rules for validating authorization responses link revision 2026-07-28; ChatGPT presents an OpenAI-managed client certificate for mutual Transport Layer Security (mTLS). <Cite ids="src-scn-chatgpt-plugin-auth" /> Sign in with ChatGPT is an OpenID Connect provider (issuer `https://auth.openai.com`) available to selected commercial partners through a limited trial; OpenAI strongly recommends it for commerce and says a ChatGPT identity is not purchase approval. <Cite ids="src-scn-chatgpt-siwc-quickstart src-openai-commerce-siwc" /> In March 2026 trade press reported an OpenAI spokesperson saying that Instant Checkout was moving to Apps (reported). <Cite ids="src-retailsystems-pivot" /> OpenAI's merchant page says there are no fees for purchases made on the merchant's own site or app (read 2026-11-14). <Cite ids="src-chatgpt-merchants" />
