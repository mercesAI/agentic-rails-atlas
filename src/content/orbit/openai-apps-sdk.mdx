Apps built with the SDK connect ChatGPT to a developer's MCP server. Its monetization guide makes external checkout generally available and has a ChatGPT payment sheet in private beta: the widget calls `window.openai.requestCheckout`, ChatGPT sends a payment token to the developer's MCP server in a `complete_checkout` tool call, and the merchant's PSP (Adyen, Checkout.com, Fiserv, PayPal, Stripe or Worldpay) charges it. <Cite ids="src-openai-apps-monetization src-stripe-apps-mcp" /> Raw payment methods require the [ACP](/p/openai-acp/) Delegate Payment endpoint and PCI DSS Level 1, and the ACP README points merchants to OpenAI's implementation for ChatGPT. <Cite ids="src-openai-apps-monetization src-openai-acp-readme" /> In March 2026 trade press reported an OpenAI spokesperson saying that Instant Checkout was moving to Apps (reported). <Cite ids="src-retailsystems-pivot" />
