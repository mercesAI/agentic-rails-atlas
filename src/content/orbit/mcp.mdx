## What it is

MCP standardizes how an AI application talks to a server that offers capabilities. The client usually lives inside a chat product or coding agent, and the server exposes tools the client can call, resources it can read and prompts it can insert. Messages are JSON-RPC 2.0 between hosts, clients and servers, carried over stdio or Streamable HTTP. <Cite ids="src-gloss-mcp-spec" />

## Status

MCP is live and uses dated specification revisions; the atlas reads revision 2025-11-25. <Cite ids="src-gloss-mcp-spec" /> On 2025-12-09 the Linux Foundation announced the Agentic AI Foundation (AAIF), with Anthropic contributing MCP alongside Block's goose and OpenAI's AGENTS.md. The founding platinum members were Amazon Web Services, Anthropic, Block, Bloomberg, Cloudflare, Google, Microsoft and OpenAI. <Cite ids="src-gloss-aaif-lf" />

## How it relates to the eight

For agentic payments MCP is the plumbing that other rails ride on. Several of the eight define how their messages travel inside MCP calls.

- [x402](/p/x402/) defines an MCP transport: a tool result with `isError: true` carries the `PaymentRequired` data, the client retries with payment in `_meta["x402/payment"]`, and settlement comes back in `_meta["x402/payment-response"]`. <Cite ids="src-x402-transport-mcp-v2" /> The project publishes an `@x402/mcp` package. <Cite ids="src-x402-npm-downloads" />
- [MPP](/p/stripe-mpp/) has a draft JSON-RPC and MCP transport for its Payment authentication scheme, with capability advertisement and payment data placed in MCP's `_meta`. <Cite ids="src-stripe-mpp-mcp-transport" />
- [ACP](/p/openai-acp/) added an MCP transport binding in its 2026-04-17 release; its OpenRPC file defines MCP tools that map one to one to the REST checkout operations, with authentication handled at the MCP server level. <Cite ids="src-openai-acp-changelog-20260417 src-openai-acp-mcp-binding src-openai-acp-openrpc-20260417" />
- [UCP](/p/ucp/) lists MCP as a transport with an OpenRPC schema, specifies Streamable HTTP rather than SSE, and applies the same RFC 9421 signature rules to MCP POST requests. <Cite ids="src-ucp-mcp-openrpc src-ucp-signatures" />
- [ERC-8004](/p/erc-8004/) registration files accept an `MCP` service entry with endpoint and version, and feedback entries may name an MCP tool, prompt or resource. <Cite ids="src-erc-8004-spec" />
- [AP2](/p/ap2/) samples run merchant, credentials provider and payment processor roles as MCP servers, and the AP2 FAQ says an SDK and an MCP server are being worked on. <Cite ids="src-ap2-repo src-x402-ap2-repo src-ap2-faq" />
- For [Visa TAP](/p/visa-tap/), Visa runs a remote MCP server for its Intelligent Commerce APIs. Its `visa/ai` repository holds MCP client and token manager packages, which were not on npm as of 2026-10-19. TAP itself does not depend on MCP. <Cite ids="src-visa-ai-repo src-visa-mcp-server src-visa-tap-npm-search" />
- For [Mastercard Agent Pay](/p/mastercard-agent-pay/), Mastercard ships the `@mastercard/developers-mcp` server package, which is a general developer tool rather than an Agent Pay component. <Cite ids="src-mcap-npm-mcp" />
