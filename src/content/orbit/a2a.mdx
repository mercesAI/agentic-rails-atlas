## What it is

A2A gives an agent a published Agent Card, a JSON document that describes its skills, endpoints and security schemes, plus a task model that a client agent drives across a network boundary. Tasks carry messages and artifacts and move through states such as `input-required`. The public Agent Card is served at `/.well-known/agent-card.json`, and the specification separates the application protocol from its JSON-RPC, gRPC and HTTP transport bindings. <Cite ids="src-gloss-a2a-spec" />

A2A is often compared with MCP: MCP connects one application to the tools and data it uses, while A2A connects agents to other agents. <Cite ids="src-arxiv-2505-02279" />

## Status

A2A is live and published as a Linux Foundation project. <Cite ids="src-gloss-a2a-spec" /> On 2025-08-29 the LF AI and Data Foundation announced that IBM's Agent Communication Protocol (not OpenAI's ACP) was joining forces with A2A. <Cite ids="src-ibm-acp-a2a" />

## How it relates to the eight

In the payments orbit A2A is a transport and a container for extensions.

- [AP2](/p/ap2/) calls itself an open extension for A2A (and for MCP and UCP), and its Python samples run merchant, credentials provider and payment processor agents that talk over A2A. <Cite ids="src-ap2-site src-ap2-repo" />
- For [x402](/p/x402/), the `a2a-x402` repository defines the x402 Payments Extension v0.1 with the extension URI `https://github.com/google-a2a/a2a-x402/v0.1` and the payment states `payment-required`, `payment-submitted` and `payment-completed`. <Cite ids="src-ap2-a2a-x402-v01 src-x402-a2a-repo" /> x402 v2 carries a matching A2A transport that signals payment with the task state `input-required` and `x402.payment.status` metadata. <Cite ids="src-x402-transport-a2a-v2" />
- [UCP](/p/ucp/) defines an A2A binding for its checkout capability, and businesses that support it publish an agent card endpoint. <Cite ids="src-ucp-a2a" />
- [ERC-8004](/p/erc-8004/) registration files can list an `A2A` service that points to an agent card, and feedback entries can reference A2A skills, `contextId` and `taskId`. <Cite ids="src-erc-8004-spec" />

No direct A2A binding was found in the cloned specs of ACP, MPP, Visa TAP or Mastercard Agent Pay.
