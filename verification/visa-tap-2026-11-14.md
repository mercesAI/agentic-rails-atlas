## What changed outside the site
- By 2026-11-14 Visa's TAP API reference also published the Visa Merchant Registry Service (VMRS, bundle TRAP.102, public): nine sandbox operations and 15 schemas for registering merchants and their payload-encryption keys, which start deactivated. Per the site's source note it was absent on 2026-10-19, when the site saw a v1 entry with one endpoint (kept as dated history); no release note mentions it, and its first appearance is undated because the Wayback Machine answered 429.
- 2026-10-20: Visa, BILL and Billtrust announced a live business-to-business pilot. BILL's Payment Agent, registered using TAP and the Agentic Directory, pays buyer-approved invoices, and Billtrust's supplier portals verify it with TAP. Visa calls it the first live pilot of agent invoice payments end to end through supplier portals (not the directory's first use) and gives no counts.
- 2026-10-24: Visa reissued its public rules and its US interchange schedule as 2026-10-24 editions (files dated 2026-10-29). The agent rules moved from section 4.1.24 to 4.1.23 with the same rule IDs and no agentic change; the login-ID dispute evidence took effect on the date the site gave; the schedule still has no agentic category, so the site's statement about the April 2026 schedule stays true, and the source titles now name the new editions.
- 2026-10-27: on Visa's earnings call (third-party transcript, reported), the CEO said nearly 50 AI partners were live and in production and named TAP and the Agent Directory as VIC's trust for the agent; the figures appear only on the Visa Intelligent Commerce orbit page.
- 2026-10-28 to 2026-11-14: mppx 0.16.0 replaced request attestation with per-route identity and moved TAP to `mppx/extensions/identity/tap`; 0.18.0 (2026-11-09) changed the identity status codes; 0.19.0 (2026-11-14) made the TAP prover take a key pair. The MPP docs moved from /advanced/identity to /extensions/identity (the old address redirects). The SDK row (0.14.1 as of 2026-10-21) and the code samples, pinned to 0.14.1, now follow 0.19.0.
- 2026-10-29: Web Bot Auth working group draft -01 replaced -00, which claim 104 had dated as current on 2026-10-11. Every Signature-Agent value is now a JWK Set URL that the verifier fetches directly; the directory, jwks_uri and cimd types are gone; -01 expires 2027-05-02.
- 2026-10-29: the EU Council adopted its first-reading positions on PSD3 and the PSR. Neither text has AI-agent provisions; both await Parliament's second reading (indicative plenary 2026-12-14) and are not in the Official Journal. The EU liability row, which dated the files to the provisional agreement of 2025-11-27, now cites the Council texts as verified.
- By 2026-11-14 Visa's VIC developer docs were public again (they asked for sign-in on 2026-10-19). They outline production onboarding (TAP, Visa Token Service, Visa Payment Passkeys and registration in the Visa Agent Registry Service), set a 30-day default US intent expiry and at most 15 cryptograms per token in a rolling 24 hours, give US merchants that support 3-D Secure a "Program Not Supported" response for agentic transactions, and state no fees. Visa's public VIC API reference, as seen that day, leads with a V2 bundle that requires a purchaseType and documents the v1 card enrollment body.
- 2026-11-13: OpenAI announced ChatGPT Wallet, rolling out first in dots for US ChatGPT Pro subscribers and built in partnership with American Express, Mastercard and Visa. No source names a Visa program or ties Wallet to TAP or VIC, and OpenAI's merchant guidance documents plain Web Bot Auth for ChatGPT's cloud browser, naming neither TAP's tags nor Visa's key store (as of 2026-11-14).
- Smaller: @visa/cli reached 5.0.0-rc.463 (published 2026-11-15 UTC; latest release still 4.0.1; the SDK row had rc.414 as of 2026-10-19); the sample repository has 222 stars and 48 forks, and issue #27 (2026-10-31) reports that its proxy rejects the RFC 9421 `keyid` spelling with 403; Cloudflare's Verified bots page (last updated 2026-11-12) needed only a source-note update here.
