## What changed outside the site
The ACP specification did not move: no commit, tag, release, advisory or maintainer comment since 2026-07-18 (main 7fdd78d, through 2026-11-14), 67 community comments since then with none from a maintainer, and community proposals such as the dispute-resolution PR 316 (ready for review on 2026-11-06) still without a sponsor. OpenAI's merchant page still says ChatGPT shopping is built on ACP and that ACP will expand to the full shopping journey (read 2026-11-14), while OpenAI's developer commerce docs, rewritten between 2026-11-12T03:49Z and 2026-11-13T17:12Z, no longer name ACP.
- 2026-11-12 to 2026-11-13: the rewrite turned the ACP developer docs into the Commerce in ChatGPT partner playbook (cloud browser access, ChatGPT Wallet, headless plugins, Sign in with ChatGPT, Business Hub, a product feed schema); the old ACP pages redirect or answer 404. OpenAI's plugin pages still offer the ACP Delegate Payment endpoint to PCI DSS Level 1 merchants, and its product checkout conversion spec now calls ACP's 2025-09-29 checkout the legacy checkout specification (changed between 2026-11-06 and 2026-11-14).
- 2026-11-13: ChatGPT Wallet, built in partnership with American Express, Mastercard and Visa, began rolling out in dots for US ChatGPT Pro subscribers (18 and older, eligible US-issued cards). It pays on the merchant's existing checkout with a network payment token after the user approves each purchase, and OpenAI does not present it as ACP. The post text names dots as the first surface; its page description and OpenAI's RSS item name agents in ChatGPT Work, Codex and dots. CNBC reports that OpenAI is not taking a cut to start (reported).
- 2026-11-10: OpenAI introduced Businesses in ChatGPT. Since the 2026-11-13 rewrite its developer docs route feed onboarding through Business Hub with identity verification, and feeds arrive as full snapshots by manual upload, hosted URL or SFTP. The feed schema's Stable view is OpenAI's flat format, its Draft view (for planning and feedback only) follows ACP 2026-04-17's Product and Variant model, and the Ads Delta Feeds API uses an ACP-shaped `PATCH /feeds/{feed_id}/products`; none of these pages names ACP.
- ChatGPT's cloud browser: OpenAI documents it as a Web Bot Auth signer (`Signature-Agent` set to `"https://chatgpt.com"`, verified by Akamai, Cloudflare, HUMAN and Vercel; signing seen since at least 2025-08-04) and is rolling out user signals in a `Forwarded` header with seven parameters, six of them unregistered at IANA. - Stripe: the seller SPT page lists three Resolve credential types (fpan, agentic_token, dpan), as its 2026-10-29 capture already did, where the site's 2026-10-20 read had also listed network_token; recurring SPTs need `usage_limits.recurring_interval`.
